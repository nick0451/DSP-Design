F114 + M34: our ledger carried an impossible BICK, and my bus numbering was wrong

F114. The firmware agent (FW-006) caught an arithmetically impossible figure in
STATE.md S0 LIVE STATUS - the block read at the start of every session - and it
reached them from there. Not damaged in transmission; wrong at rest.

We claimed AK5574 Table 9 row 26 and AK4458 Table 13 Mode 12 BOTH give BICK
128fs. A TDM8 link with 32-bit slots has 256 bit-times per frame, so it cannot
run at 128 fs. 128 fs at 32-bit slots IS TDM4.

And the refutation was already in this repo, in a file we read every session:
CLAUDE.md S6 derived digest says TDM8 = 12.288 MHz, which is 256 fs. Two
documents disagreed for days, both read repeatedly, neither review brought them
into contact. That is exactly the failure CLAUDE.md S0b names as the one this
role is exposed to, and it has now happened a second time - with the digest
right and the ledger wrong.

F70 REOPENED to T2. It was closed on a self-consistency check that does not
close arithmetically. The S4 decree itself is untouched - it is the operator's
act and does not depend on it. Only the supporting claim is withdrawn. I
declined to send the firmware agent the two table rows they asked for, because
I do not have either table read at figure level and would have been reciting.

The tell, now in the ledger: the word BOTH. A single figure asserted to hold
across two different link formats is a compression, and compression is where
distinctions die.

M34. We both allocated seq 004 within 22 seconds. My justification for one
shared counter in bus 001 was FALSE: I wrote that per-folder numbering hides a
loss because each side's own count still looks complete - but a lost message
leaves the RECEIVER seeing a gap. I reasoned about the sender's view, and the
sender is not who detects a drop. So the shared counter carried an allocation
race in exchange for a benefit that did not exist.

A gap is loud. A collision is SILENT - both folders look internally consistent,
every number present, two messages sharing one identity. F109's shape in a
protocol: the check passed because it could not fail.

Adopted parity, hw ODD / fw EVEN - swapped from their proposal, because the
history and their own 005 reservation both point that way.

ways, 85 ms vs 21.25 ms, and we take 85 on safe-direction grounds that survive

not a property of the part - D-5 stands but my 85-ms-free framing needs
